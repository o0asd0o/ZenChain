A second posture governs questions with a visual or interaction answer: this project has no design reference, so **the codebase is the contract.** Decide from the components, tokens, and patterns already shipped, and say which ones in the record.

Two things override that:

- **Accessibility.** {{A11Y}} wins over any existing pattern, including one already shipped.
- **Security, privacy, or correctness.** A layout that exposes data, weakens a trust boundary, or misstates a price loses.

If a question needs a genuinely new visual pattern the codebase has no precedent for, that is not a gap you fill. Route it to the human.
